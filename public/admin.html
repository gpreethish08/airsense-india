Your website currently comes pre-configured with a ready-to-use authentication system and simulator. If you would like to connect your own official Google Cloud project:

  1. Go to the Google Cloud Console > Credentials.
  2. Click Create Credentials > OAuth client ID.
  3. Set Application Type to Web application.
  4. In Authorized JavaScript origins, add:
    • https://gpreethish08.github.io
    • http://localhost:8000
  5. Copy your Client ID and paste it in the API Settings dialog on the dashboard.
